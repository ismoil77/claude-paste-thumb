# paste-thumb

Небольшой мод для [Claude Code](https://claude.com/claude-code). Когда вставляешь картинку в строку
ввода, прямо над ней появляется миниатюра в рамке с номером картинки. Видно, что именно ты
прикрепил, ещё до отправки.

[English version](README.md)

## Установка

В строке ввода терминальной сессии:

```
/plugin install paste-thumb --marketplace ismoil77/claude-paste-thumb
```

Из шелла:

```
claude plugin install paste-thumb --marketplace ismoil77/claude-paste-thumb
```

Ответь `y` на вопрос про маркетплейс и выбери область. С областью «пользователь» мод грузится в
каждой сессии. Рисует он только в терминале, в приложении для рабочего стола его нет.

## Что нужно

- Терминал, который рисует картинки по протоколу kitty: [Ghostty](https://ghostty.org) или kitty. В
  остальных вместо картинки в рамке будет текст `[Image #1]`. Терминал должен работать на том же
  компьютере, что и Claude Code: файлы картинок он читает сам, поэтому по ssh рамка может остаться
  пустой.
- `od`, `id` и `sh`, они есть в Linux и macOS.
- PNG показывается как есть. Claude Code обычно сохраняет вставленные картинки в PNG; любой другой
  формат, который он оставит (JPEG, WebP, GIF, BMP, TIFF, AVIF, HEIC, насколько их читает твой
  ImageMagick), один раз уменьшается до маленького PNG, только первый кадр. Для этого нужен
  [ImageMagick](https://imagemagick.org) (`magick` или `convert`). Без него показываются только PNG,
  и мод один раз за сессию скажет об этом при первом файле другого формата.
- Разработано и используется на Linux с Claude Code 2.1.312; на macOS не пробовалось.

### Внутри herdr, tmux и других мультиплексоров

Claude Code узнаёт, рисует ли терминал картинки, спросив его, а мультиплексор может ответить за
себя. Задай `CLAUDE_CODE_FORCE_TERMINAL_IMAGES=1` в окружении, где запускаешь Claude Code, и запусти
мультиплексор внутри Ghostty или kitty. [herdr](https://herdr.dev) рисует графику kitty, когда её
рисует его внешний терминал (настройка `terminal.kitty_graphics`, по умолчанию включена); тестовая
картинка в herdr внутри Ghostty отрисовалась верно. tmux не проверялся.

## Как работает

- Два раза в секунду ищет в черновике теги `[Image #N]`.
- Находит файл, который Claude Code сохранил под этим номером, в
  `<tmp>/claude-<uid>/<проект>/<сессия>/images/` (`<tmp>` это `$CLAUDE_CODE_TMPDIR` или `/tmp`).
  Если файла ещё нет, на каждом опросе ищет снова около десяти секунд, а если так и не появился,
  один раз об этом скажет.
- PNG терминал читает прямо оттуда. Берётся только размер, из первых 24 байт файла командой `od`.
  Ничего не копируется.
- Другие форматы ImageMagick уменьшает до 480 px в `$TMPDIR/claude-paste-thumb/<сессия>` (`$TMPDIR`
  или `/tmp`). Папка создаётся, только когда нужна конвертация, и удаляется при выходе из сессии;
  пустая родительская остаётся, а если процесс убит, ничего не удаляется.
- Миниатюра не выше 10 строк и не шире 48 ячеек, пропорции картинки сохраняются.
- После `/clear` или возобновления сессии мод переходит на папку новой сессии.

## Ограничения

- Папка, где Claude Code хранит вставленные картинки, нигде не задокументирована. Если обновление
  Claude Code её переместит, миниатюры перестанут показываться, пока мод не обновят.
- Моды в Claude Code пока в раннем доступе, API может измениться.
- Увеличения по клику нет. Картинка не принимает кликов, а панель, открытая кнопкой, в узком
  терминале при проверке была сообщена как не нарисованная.

## Разработка

```
claude plugin validate .
claude plugin test .
```

Логика, которой не нужен Claude Code (теги, пути, заголовок PNG, размер картинки), лежит в
`hooks/thumb.ts`, а хуки в `hooks/register.tsx`. Тесты подменяют сторону движка, в том числе часы.
